# AR-визитка

Веб-приложение дополненной реальности: наводишь камеру смартфона на печатную визитку, и над ней появляется 3D-визитка с контактами владельца. Работает в браузере без установки (Safari на iOS, Chrome на Android).

Курсовая работа по дисциплине «Разработка кроссплатформенных приложений дополненной реальности», РТУ МИРЭА.

Приложение: https://alexirkhin.github.io/business_card_AR/

## Возможности

- Распознавание печатной визитки камерой (image tracking) и 3D-визитка над ней: появление, парение, сглаживание дрожания.
- Две стороны: имя с ролью и кнопки контактов. Нажатие переворачивает визитку, кнопки на обороте звонят, пишут, открывают Telegram и GitHub, сохраняют контакт (vCard).
- Режим осмотра: кнопка «Осмотреть визитку» переносит 3D-визитку с маркера в центр экрана, где её можно вращать, масштабировать и двигать жестами. Если маркер ушёл из кадра, визитка переходит в этот режим сама.
- Резервная панель контактов и понятные сообщения, если камера недоступна.
- Предпросмотр 3D-визитки без камеры (`?preview=1`).
- Конструктор: своя визитка без правки кода.

## Как пользоваться

1. Открыть приложение по QR-коду с печатной визитки или по ссылке выше.
2. Нажать «Запустить камеру» и разрешить доступ.
3. Навести камеру на печатную визитку (или на `assets/marker.png` на экране) с расстояния 20–50 см.
4. Нажать на 3D-визитку, чтобы увидеть контакты; «Осмотреть визитку» — чтобы взять её «в руку».

Нужен Safari на iPhone или Chrome на Android; во встроенных браузерах мессенджеров камера может быть недоступна. На компьютере с веб-камерой приложение тоже работает.

## Как это устроено

- Сборки нет: чистые ES-модули, библиотеки лежат в `vendor/`, сторонние CDN не используются.
- MindAR находит маркер в кадре и сообщает его положение; Three.js рисует визитку поверх видео.
- 3D-визитка строится программно: корпус со скруглёнными углами, стороны рисуются на canvas по данным из `config.json`.
- Нажатия определяются лучом из точки касания (raycasting) по невидимым областям кнопок.
- Положение на маркере сглаживается: мелкое дрожание гасится сильно, за быстрым движением визитка успевает.

## Как сделать свою визитку

Код менять не нужно. Все файлы визитки собирает конструктор:

1. Открыть конструктор: https://alexirkhin.github.io/business_card_AR/tools/constructor.html (или локально, http://localhost:8000/tools/constructor.html).
2. Заполнить форму: имя, роль, контакты, цвет, адрес своего сайта на GitHub Pages. 3D-визитка и печатная визитка в предпросмотре меняются сразу, ошибки ввода показаны под полями.
3. Скачать `config.json`, `marker.png` и собрать `targets.mind`.
4. Положить `config.json` в корень своей копии репозитория, а `marker.png` и `targets.mind` — в папку `assets`. Сделать коммит и пуш.
5. Распечатать лист А4 кнопкой «Печать листа А4» (в окне печати включить фон и масштаб 100 %) или показать `marker.png` на экране.

Лицевая сторона печатной визитки (90×50 мм) одновременно служит маркером для AR, поэтому после любого изменения данных маркер и файл трекинга нужно скачать заново. Конструктор ничего не отправляет на сервер: файлы собираются в браузере, черновик формы хранится там же.

### Формат config.json

Файл можно править и вручную:

```json
{
  "name": "Александр Ирхин",
  "role": "Системный аналитик",
  "phone": "+7 988 675-02-07",
  "email": "xsx99@mail.ru",
  "telegram": "https://t.me/irhin21",
  "github": "https://github.com/AlexIRKHIN",
  "theme": { "accent": "#4f8cff" },
  "url": "https://alexirkhin.github.io/business_card_AR/"
}
```

- Обязательное поле одно: `name`. Из него же получается монограмма (первые буквы первых двух слов).
- Если контакт не указан или указан с ошибкой, его кнопка не показывается.
- `telegram` и `github` можно писать ссылкой или именем пользователя (`@irhin21`, `AlexIRKHIN`).
- `theme.accent` задаёт цвет оформления в формате `#rrggbb`.
- `url` — адрес опубликованного приложения, он кодируется в QR-коде на печатной визитке.

Готовые файлы для текущего конфига лежат в репозитории: `assets/marker.png`, `assets/targets.mind`, `print/card.pdf` (одна визитка), `print/sheet-a4.pdf` (десять на листе).

## Запуск на компьютере

Нужен любой локальный веб-сервер (открыть `index.html` двойным щелчком не получится: браузер не даст загрузить модули и конфиг).

```
python -m http.server 8000
```

После этого открыть http://localhost:8000. 3D-визитка без камеры: http://localhost:8000/?preview=1. На телефоне приложение проверяется через GitHub Pages: камера работает только по HTTPS.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)`. Сборка не требуется.

## Структура

```
index.html        страница приложения
config.json       данные визитки
css/style.css     стили 2D-интерфейса
js/main.js        точка входа, выбор режима
js/config.js      загрузка и проверка конфига
js/ui.js          стартовый экран, подсказки, ошибки, панель контактов, подсказки по жестам
js/card.js        3D-визитка: корпус, грани, области кнопок, декоративная фигура
js/card-textures.js  отрисовка сторон визитки на canvas по данным конфига
js/animations.js  появление, парение, переворот, вращение фигуры
js/interaction.js raycasting: нажатия на визитку и кнопки, действия контактов
js/preview.js     режим предпросмотра без камеры
js/gestures.js    жесты: вращение, масштаб, перемещение
js/ar.js          AR-режим: камера, MindAR, состояния «на маркере» и «в руке»
js/vcard.js       формирование файла .vcf
js/icons.js       иконки контактов и жестов
tools/constructor.html  конструктор визитки: форма, предпросмотр, выдача файлов
tools/constructor.js    логика конструктора: проверка, черновик, скачивание, сборка targets.mind
tools/constructor-viewer.js  3D-предпросмотр в конструкторе
tools/marker-draw.js    отрисовка печатной визитки (маркера)
assets/fonts/     шрифт Inter
assets/marker.png изображение-маркер (лицевая сторона печатной визитки)
assets/targets.mind  файл трекинга MindAR, собранный из маркера
print/            макеты для печати (PDF)
vendor/           Three.js, MindAR, генератор QR-кодов
```
